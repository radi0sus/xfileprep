Tip: for a reflection file plus a separate cell-info file (e.g. .hkl + .ins, or .hkl + .p4p), drop them in either order — whichever one carries the cell (.ins/.p4p/CIF) fills in the cell constants (and composition/wavelength where available), and whichever one carries reflections (.hkl or a CIF with a reflection loop) triggers the automatic Laue/absences/space-group run. Dropping the cell-info file after the reflections just fills in the missing piece and re-runs everything automatically. That run also switches you to the "Space Group" tab once it lands on a candidate table (the SHELX .ins tab is prepared for the top candidate at the same time — check it any time, no extra click needed).

Zone plots (reciprocal lattice)

Each square/dot is one aggregated grid position (duplicate observations merged): ● filled green = at least one significant reflection measured there; ● light gray = measured but every observation was weak (I/σ < 3); blank = no reflection at that position at all. A clean checkerboard or every-other-row pattern is the visual signature of a glide plane / screw axis.
